## 🚀 Selected Projects

### 🕹️ [Neon Drift](https://github.com/fierce-bri/neon-drift) · [▶ Play in your browser](https://fierce-bri.github.io/neon-drift/)
A neon top-down arena survival shooter made in **Godot 4** and exported to **HTML5**. You move with WASD and aim with the mouse while surviving waves of four enemy types (chaser, dasher, shooter and splitter). It has health and rapid-fire pickups, a combo multiplier up to ×8 and a saved best score. Glow post-processing, particles, screen shake, generated sound effects and touch controls round it out. The code is organised into scenes, scripts and a global game-state autoload.

### 📝 TextRank Full-Stack Summarization Application
A full-stack extractive summarization application built with **React, Node.js, Express, PostgreSQL, FastAPI, scikit-learn and NetworkX**. It began as a university NLP notebook and grew into a multi-service application. It now has a browser interface, REST APIs, persistent summary history, database constraints, automated Node and Python tests, Docker tooling and GitHub Actions.

### ✍️ Literature Lab
A **Django creative-writing assistant** with a responsive browser interface and a JSON API. It supports structured workflows for analysing drafts, brainstorming story directions, planning revisions and continuing scenes. It has persistent interaction history, validation, automated tests, Docker packaging and CI.
